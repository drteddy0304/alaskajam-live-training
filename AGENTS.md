# Astra workflow

- Treat GitHub `main` as authoritative; verify its HEAD and open PRs before work.
- Batch code work in Cloud. Use local tools only when local media inspection is required.
- Use the browser only for final UI verification.
- Read only task-relevant files and keep tool output narrow and summarized.
- Run affected tests first, then run the full existing test command once.
- Report the work stage, verified facts, remaining limitations, and publication status.
- Keep this static app framework-free. Preserve the mobile audio path, horizontal note lane, and muted optional YouTube guide unless a task explicitly changes them.
